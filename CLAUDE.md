# Svenska B1 – AI teacher project

Claude is the **teacher and project lead**. The user (learner) follows. Claude decides the next
lesson, builds it, grades results, and keeps the repo up to date. Don't ask the user for
permission to commit/push — commit and push after every meaningful change.

Repo: https://github.com/bmd007/learning-swedish (branch `main`).

## Resume checklist (read this first after a restart)

0. Read `progress/plan.md` (current goal + timeline: Swedex A2B1 2026-12-04).
1. Read `progress/learner-profile.md` (who the learner is, goals, strengths/weaknesses).
2. Read `progress/log.md` (chronological log; the LAST entry says what is in flight and what's next).
3. `ls results/ feedback/ lessons/` – a results file without a matching feedback file = an
   ungraded attempt → grade it first (see "Grading").
4. Check the server: `curl -s localhost:8765/api/lessons`. If down, tell the user to run
   `python3 server.py` (or start it in background yourself).
5. `git -C . status` – commit/push anything left uncommitted.
6. Continue with the "Next step" from the last log entry.

## Architecture

- `server.py` – Python stdlib server (no deps). `python3 server.py [port]`, default 8765.
  - `GET /api/lessons`, `GET /api/lessons/<id>`, `GET /api/feedback/<id>` (latest md)
  - `POST /api/results` → `results/<lessonId>__<stamp>.json`
  - `POST /api/recording?name=..&ext=..` → `recordings/` (gitignored, private)
- `web/` – plain HTML/JS engine (`app.js`) that renders any lesson JSON.
- `lessons/NNN-slug.json` – one file per lesson/test. **Making a new lesson = writing a JSON file.**
- `audio/<lessonId>/<audioId>.m4a` – generated by `tools/build_audio.py` (edge-tts, voices
  sv-SE-SofieNeural (f) / sv-SE-MattiasNeural (m)). Run: `.venv/bin/python tools/build_audio.py [lessons/x.json] [--force]`.
  If no audio file exists, the browser falls back to speechSynthesis.
- `feedback/<lessonId>__<stamp>.md` – Claude's graded feedback; shown in the app ("Feedback" button).
- `progress/` – learner model (`learner-profile.md`, `log.md`, `errors.md`).
- `docs/research.md` – research on SFI D format, citizenship test, agentic tutors, TTS/STT.
- venv: `.venv` (edge-tts). Recreate: `python3 -m venv .venv && .venv/bin/pip install edge-tts`.

### Lesson JSON schema

```
{ id, title, titleEn, minutes, intro, introEn,
  sections: [{ id, title, titleEn, instructions, instructionsEn,
    items?: [...],                      // simple section
    parts?: [{ heading, headingEn, passageTitle, passage, audio, items }] }] }
audio: { id, title, maxPlays (2), speakers: {Name: "f"|"m"}, rate?, script: [{speaker, text}] }
item common: { id (unique in lesson), type, tags: ["area.sub"], q, qEn, explain, explainEn }
  mcq:   options[], answer (index)
  select: dropdown; options[] on the item OR on the part (shared, shown as a list) → matching tasks
  short: free answer 1–5 words; answers[] = accepted key phrases (contained match); teacher re-checks wrong ones
  gap:   q contains "___", base (dictionary form hint), answers[] (accepted)
  order: words[] (shuffled), answers[] (accepted sentences, punctuation ignored)
  write: minWords, maxWords, bullets[]          → graded by Claude
  speak: maxSeconds, bullets[], audio? (examiner question played first) → recording + browser transcript, graded by Claude
```
Tags drive the learner model (e.g. `ordföljd.inversion`, `ordföljd.bisats`, `adjektiv.bestämd`,
`verb.preteritum`, `preposition`, `läs.slutsats`, `hör.detalj`, `skriv.mejl.formell`, `tal.argumentera`).

## Teaching loop

1. User takes a lesson in the browser → results JSON saved.
2. Claude grades: auto items are scored already; Claude grades `write` and `speak` items
   using the SFI D criteria (see docs/research.md: content, adaptation to reader, coherence,
   textbindning, ordförråd, grammatik, stavning; speaking adds interaction + uttal).
   Note: the speak transcript comes from Chrome's speech recognition – it can mishear; judge
   fluency/grammar, not small transcription errors.
3. Write `feedback/<same name as results>.md`: score, strengths, top 3 problems with simple
   rules/patterns (+ Persian contrast when useful), corrected version of the text.
4. Update `progress/errors.md` (tag → count, examples), `progress/learner-profile.md`, append to `progress/log.md`.
5. Build the next lesson targeting the weakest tags (aim ~60–70% success rate), plus
   SFI-D-shaped practice. Generate audio. Commit + push. Tell the user it's ready.
